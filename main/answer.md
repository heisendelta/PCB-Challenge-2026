# 4-Word × 4-Bit Asynchronous FIFO with an ESP32-S3 Reader

## Project Description

This board is a **4-word × 4-bit asynchronous FIFO** (first-in, first-out buffer). An external device writes 4-bit words in through pin headers J4/J5, timed by the on-board oscillator clock. An ESP32-S3 reads them out with its own, independent clock. Because the two sides run from unrelated clocks, each side keeps its own pointer and passes it to the other side through a two-flip-flop synchroniser. The FIFO reports **full** to the writer and **empty** to the reader, so neither side overruns the buffer.

## Functional Blocks

### Power Supply
A USB-C connector (J3) with 5.1 kΩ CC pull-downs supplies 5 V. A TC1262 linear regulator (U9) makes the logic rail. A green LED shows 5 V and a blue LED shows the logic rail. The USB data lines also go to the ESP32 for programming.

### Clocks
- **Write clock, `clk`:** from the Y2 crystal oscillator module. It clocks the write pointer, the full flag, the memory's write port and the read-pointer synchroniser. It also appears on J5 pin 3, so the writer can time its data against it.
- **Read clock, `IO6`:** generated by the ESP32 firmware. It clocks the read pointer, the empty flag, the output register and the write-pointer synchroniser.

### Write Side (J4 / J5)
- **Data:** `b1`–`b4` on J4 is the 4-bit word to store.
- **Write request, `en`:** on J5 pin 1. It is ANDed with "not full" to make the write enable `R_en`.
- **Reset, `rst`:** on J5 pin 2. Clears the write side.
- **Full flag:** on J5 pin 4, labelled `????` in the schematic.
- **Write pointer:** a 3-bit counter, made of three flip-flops (U17, U19, U20), a 74HC283 adder wired as "+1" (U28) and 2:1 muxes that choose between "hold" and "+1". The low two bits address the memory; the top bit is a wrap bit that tells full from empty.

### Memory
U10 stands in for a 4 × 4 dual-port memory. It writes on `clk` at the write-pointer address and reads asynchronously at the read-pointer address. The schematic note says the part doesn't exist; it replaces the extra muxes and flip-flops a real memory would need.

### Clock-Domain Crossing
- The write pointer goes into the read domain through two flip-flops per bit (U39–U50), coming out as `wir1`–`wir3`.
- The read pointer goes into the write domain the same way (U29–U38, U4/U5), coming out as `reg1`–`reg3`.
- A mux in front of each synchroniser flip-flop clears it during reset.

### Flags
- **Full** = the pointers' low two bits match and their wrap bits differ (XOR/AND logic U3, U18, U51–U54, U27). The result is registered in U1.
- **Empty** = all three bits match (U55–U63). The result is registered in U65 and forced on during a read-side reset.

### Read Side (ESP32-S3, U25)

| Port | Direction | Role |
|------|-----------|------|
| IO6  | ESP32 → FIFO | **Read clock.** Every read-side flip-flop is clocked on this. |
| IO7  | ESP32 → FIFO | **Read request.** ANDed with "not empty" to make the read enable `r_en`. |
| IO8  | ESP32 → FIFO | **Read-side reset** (active high, pulled down by 7 × 10 kΩ). Clears the read pointer, the output register and the synchronised write pointer, and forces empty on. |
| IO9  | FIFO → ESP32 | **Empty flag.** Firmware checks it before reading. |
| IO10 | FIFO → ESP32 | **Read data bit 1** (output register U69) |
| IO11 | FIFO → ESP32 | **Read data bit 2** (U68) |
| IO12 | FIFO → ESP32 | **Read data bit 3** (U67) |
| IO13 | FIFO → ESP32 | **Read data bit 4** (U66) |

The read pointer mirrors the write pointer: flip-flops U6–U8, a "+1" adder U22, and muxes U11–U13. When `r_en` is high on an `IO6` edge, the word at the read address is loaded into the output register (U66–U69, through muxes U70–U73) and the read pointer moves on by one.

### Resets
Each side has its own active-high synchronous reset: `rst` for the write side and `IO8` for the read side. The muxes in front of the pointers, synchronisers and flags load 0 during reset. NPN transistors (Q15–Q29) are also meant to pull those nodes low, because the flip-flops have no clear pin.

## One-Line Summary

> A 4-deep, 4-bit asynchronous FIFO: an external writer clocks words in on the oscillator clock through J4/J5, an ESP32-S3 reads them out on its own clock (IO6–IO13), and 3-bit pointers passed through two-flip-flop synchronisers produce the full and empty flags.

## Possible Issues

- **The flip-flops only have an inverted output.** The 74AUP1G80 drives only ~Q, but the schematic uses it as Q. With the muxes set to "hold", the pointers and the output register toggle on every clock instead of holding, and the full and empty flags (`????`, `IO9`) have the opposite meaning.
- **The pointers cross clock domains in plain binary, not Gray code.** Several bits can change at once, so the other side can sample a pointer value that never existed.
- **`COUT` shorts two adder outputs together** (U22 pin 9 and U28 pin 9).
